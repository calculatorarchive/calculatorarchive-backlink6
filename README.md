## Deployment

This is a static HTML page that can be deployed to:

1. **GitHub Pages**: Push to a repository and enable GitHub Pages in settings
2. **Netlify**: Drag and drop the folder to Netlify
3. **Vercel**: Connect your Git repository to Vercel
4. **Any web server**: Upload the files to any hosting provider

### GitHub Pages Deployment

1. Create a new repository on GitHub
2. Upload all files to the repository
3. Go to Settings > Pages
4. Select the branch to deploy from (usually `main` or `master`)
5. Your site will be live at `https://<username>.github.io/<repository-name>/`
